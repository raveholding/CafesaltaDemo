# Cafetería Salta · Demo Sistema RAVE (VB 26)

Demo HTML5 de un solo archivo (`index.html`), sin dependencias ni servidor. Café de especialidad · pet friendly.

- Menú público/turnero: abrir `index.html` (o `?mesa=I5`, `?mesa=E2` para la carta de una mesa).
- Acceso del equipo: `index.html#acceso` — ADMIN · 1234 (más usuarios de prueba en la pantalla de acceso).
- Datos: *Configuración → Datos de la demo* permite **Cargar datos de ejemplo** o **Vaciar demo (en blanco)**.
- Los datos se guardan en el navegador (localStorage). Todos los datos son de ejemplo.
